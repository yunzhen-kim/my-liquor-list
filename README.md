# 나의 술창고

보유 중인 꼬냑·위스키·와인·기타 증류주를 종류별, 브랜드별로 정리한 목록입니다.

- 사이트: https://yunzhen-kim.github.io/my-liquor-list/
- 병 추가: `index.html`의 `BOTTLES` 배열에 항목을 하나 더 넣으면 됩니다.
- 구조: 꼬냑 / 위스키(블렌디드·싱글몰트 → 일본·스카치·잉글랜드·버번·한국·독립병입자 → 브랜드) / 와인 / 기타 증류주. 위스키 병은 `region` 값으로 원산지 칸이 정해지며, 병이 없는 원산지 칸은 표시되지 않습니다.

## 술장 검색 (대화창)
- 오른쪽 아래 **술장 검색** 버튼을 누르고 한국어나 영어로 물어보면 맞는 병을 찾아 보여줍니다. 결과를 누르면 해당 병으로 이동합니다.
- 기본 검색: 설정 없이 동작. 브랜드·종류·캐스크·숙성연수 조건(예: `30년 이상 위스키`, `Hennessy XO`, `1993`)을 이해합니다. 새 표현은 `index.html`의 `SYNONYMS` 목록에 한 줄 추가하면 됩니다.
- AI 모드(선택): 대화창의 **AI 설정**에 본인의 Anthropic API 키를 넣으면 Claude가 자유로운 질문(예: `선물하기 좋은 꼬냑`)에 답합니다. 키는 그 기기 브라우저에만 저장됩니다.
